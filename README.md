# PTAAU Hub

Digital platform for the **Pharmacy Technicians and Assistants Association of Uganda (PTAAU)**.

## Overview

PTAAU Hub supports association operations with a modern web experience for members, leadership, and institutional visibility.

## Focus

- Association digital presence and member-facing workflows
- Healthcare professional community tooling
- Secure, maintainable TypeScript web architecture

## Stack

- TypeScript
- Modern React / Next.js patterns
